BirdoVPN — F-Droid repository

Fast, private, quantum-resistant VPN · installs & updates via F-Droid, no Google Play required

This is BirdoVPN's self-hosted F-Droid repository. Add it to your F-Droid client to install BirdoVPN and receive automatic updates. Every APK here is the same developer-signed build published on GitHub Releases.

1. Install an F-Droid client

If you don't have one yet, get F-Droid or a compatible client (Neo Store, Droid-ify).

2. Add this repository

Open your F-Droid client → Settings → Repositories → + and paste the URL below (it includes the signing fingerprint so the client can verify it):

3. Install BirdoVPN

Search for BirdoVPN in your F-Droid client, install it, and future releases will update automatically.

Prefer a plain APK?

You can also download the APK directly or grab it from GitHub Releases. A BirdoVPN account is required to connect.
